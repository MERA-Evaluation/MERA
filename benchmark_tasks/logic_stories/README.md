# Logic Stories

## Описание

Датасет построен на логических выражениях, превращённых в короткую текстовую историю о ситуации. В выражении есть высказывания, из которых складывается та же история. По приведённым выражению и истории модели предлагается ответить на вопрос об истинности логического выражения.

## Содержание

HF: `MERA-evaluation/logis_stories`.

## Заметки

- Проверяется корректность истории и того, что по ней можно верно ответить на вопрос об истинности приведённого логического выражения.
- Допустимы не полностью сгенерированные примеры: например, взять онтологию по предметной области и реальные сущности/высказывания, сначала по шаблону получить утверждения, затем собрать из них историю.
- Качество на полных сетах и при малом числе переменных без импликации («следования») довольно высокое.
- В условиях неопределённости качество падает. Неопределённость здесь означает, что высказывания из логического выражения заранее неизвестны или известны лишь частично.
- При генерации историй возможны несоответствия логическому выражению.
- Также можно добавить онтологию предметной области.
