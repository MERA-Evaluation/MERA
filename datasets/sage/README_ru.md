# SAGE


## Описание задачи

Датасет SAGE предназначен для оценки способности языковых моделей автоматически исправлять ошибки в русском тексте.

Он формулируется как задача преобразования текста с ошибками в корректный вариант. Модели должны исправлять орфографию, пунктуацию, грамматику и регистр букв, не добавляя комментариев и пояснений.

Данный набор является усовершенствованной версией открытого датасета SAGE (v1.1.0), опубликованного на Hugging Face: https://huggingface.co/ai-forever/sage-v1.1.0.

Набор ориентирован на text-to-text модели и позволяет количественно оценивать качество автоматической коррекции текста.

Тестируемые навыки моделей: Grammatical error correction, Spelling correction, Punctuation correction, Casing correction, Error detection, Text editing

Авторы: Данил Астафуров, Ульяна Исаева, Алёна Феногенова, Анастасия Мордашева, Наталья Атнагулова, Ольга Кун, Ольга Таболина, Кристина Еремеева, Никита Мартынов, Александр Астафуров


## Мотивация

### Целевые модели
Датасет предназначен для генеративных языковых моделей, способных редактировать текст и выполнять задачи автоматической коррекции.

### Какие способности проверяются
Оценивается способность модели:
- обнаруживать ошибки разных типов
- корректно их исправлять
- сохранять исходный смысл текста

Это не просто language understanding, а способность к языковому редактированию.

### Для кого результаты
Результаты предназначены для исследователей и разработчиков NLP-моделей, оценивающих качество текстовой генерации и постобработки текста.

### Интерпретация метрик
Метрики отражают качество исправления разных типов ошибок (регистр, орфография, пунктуация и др.), что позволяет анализировать сильные и слабые стороны моделей.


## Описание датасета

### Поля данных

Каждый вопрос в датасете содержит следующие поля:

- `instruction` [str] — Промпт-инструкция для модели, содержащая шаблон для вставки элементов вопроса.
- `inputs` — Вводные данные, формирующие задание для модели. Могут включать одну или несколько модальностей - видео, аудио, изображение, текст.
    - `source` [str] — Текст с ошибками, который необходимо исправить.
- `outputs` [str] — Правильный ответ на вопрос.
- `meta` — Метаданные, относящиеся к тестовому примеру, но не используемые в вопросе (скрытые от тестируемой модели).
    - `id` [int] — Номер-идентификатор вопроса в датасете.

### Промпты

Для задачи были подготовлены 5 промптов, которые были равномерно распределены по вопросам по принципу "один вопрос – один промпт". Шаблоны в фигурных скобках в промпте заполняются из полей внутри поля `inputs` в каждом вопросе.


Пример промпта:

```
ЗАДАЧА
Исправь орфографические, пунктуационные и грамматические ошибки в тексте, а также ошибки регистра букв.

ФОРМАТ ОТВЕТА
Выведи только исправленный текст без пояснений и комментариев.

ТЕКСТ
{source}
```


### Создание датасета

### Источники данных
Данные собраны из различных русскоязычных текстовых источников, включая открытые корпуса, интернет-тексты, пользовательские запросы и синтетически сгенерированные примеры.

### Разметка
Часть выборки была вручную переразмечена для обеспечения корректности эталонных исправлений.

### Очистка данных
Из набора были удалены пустые, дублирующиеся и некорректные записи.

### Категории ошибок
В датасете представлены следующие категории ошибок (доля сэмплов, содержащих соответствующий тип ошибки):

- CASE — ошибки регистра букв (несоответствие заглавных и строчных букв): 13.6%
- YO — ошибки в употреблении букв «е» и «ё»: 33.2%
- SPELL — орфографические ошибки: 58.0%
- PUNCT — пунктуационные ошибки: 43.2%

Проценты отражают долю сэмплов, в которых присутствует хотя бы одна ошибка соответствующего типа. В одном сэмпле может встречаться несколько типов ошибок одновременно.

### Формирование выборки
После предобработки данные были случайным образом перемешаны и разделены на итоговые наборы для оценки моделей.


## Оценка


### Метрики

Для агрегированной оценки ответов моделей используются следующие метрики:

- `CASE_F1`: Метрика CASE_F1 измеряет F1-оценку по правкам, связанным с исправлением регистра букв (заглавные и строчные). Метрика рассчитывается на уровне правок через precision и recall внутри данной категории.
- `YO_F1`: Метрика YO_F1 измеряет F1-оценку по правкам, связанным с исправлением употребления букв «е» и «ё». Метрика рассчитывается на уровне правок через precision и recall внутри данной категории.
- `SPELL_F1`: Метрика SPELL_F1 измеряет F1-оценку по орфографическим правкам. Метрика рассчитывается на уровне правок через precision и recall внутри данной категории.
- `PUNCT_F1`: Метрика PUNCT_F1 измеряет F1-оценку по пунктуационным правкам. Метрика рассчитывается на уровне правок через precision и recall внутри данной категории.
- `errant`: Метрика errant представляет собой взвешенную агрегированную F1-оценку по категориям ошибок (CASE, YO, SPELL, PUNCT). Каждая категория имеет вес, пропорциональный её распределению в датасете, с последующей нормировкой по сумме весов. Метрика отражает общее качество исправления текста с учётом относительной частоты различных типов ошибок.
