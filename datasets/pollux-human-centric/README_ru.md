# POLLUX Human Centric

## Описание задачи

**POLLUX Human Centric** — генеративный датасет для MERA Text v.2.0: **70** тестовых заданий и **5** few-shot примеров (всего 75). Примеры отобраны из [POLLUX](https://arxiv.org/abs/2505.24616) по фильтру `Human Interaction` / `Hard` / `Общее`.

Датасет проверяет качество свободной текстовой генерации по запросам на рекомендации, советы и планы действий. Ответ модели оценивается LLM-as-a-Judge (Pollux-4B-Judge) отдельно по каждому элементу `criteria`. Поле `outputs` намеренно пустое.

Тестируемые навыки: Alignment, Chain-of-Acts and Psychological & Agent Skills, Art & Cultural Analysis, Creativity

Авторы: Никита Мартынов, Анастасия Мордашева, Дмитрий Горбецкий, Данил Астафуров, Ульяна Исаева, Элина Басырова, Сергей Скачков, Виктория Берестова, Николай Иванов, Валерия Занина, Алена Феногенова

## Мотивация

Датасет предназначен для оценки способностей моделей давать экспертные ответы на сложные антропоцентричные запросы (рекомендации, советы, планы действий) в бытовых, культурных и социальных сценариях.


### Ограничения

Датасет не предназначен для оценки формальной грамотности, узкоотраслевых олимпиадных задач или написания кода. Охват ограничен запросами типа «дать рекомендацию», «дать совет», «составить план действий».

### Для кого результаты

Результаты полезны создателям чат-ботов и помощников для поддержки клиентов, культурных площадок и бытовых сценариев, а также разработчикам адаптационных и обучающих систем на базе LLM.

### Оцениваемые способности

- Адекватно понять запрос и предложить решение, согласованное с культурными и социальными нормами
- Сохранять последовательность рассуждений в ответе
- Проявлять здравый смысл (шутки, этические дилеммы, контринтуитивные условия)
- Давать содержательные ответы в востребованных областях повседневной и культурной деятельности

## Описание датасета

- `test.json` — **70** тестовых примеров (`meta.id` 6–75)
- `shots.json` — **5** few-shot примеров (`meta.id` 1–5)
- Всего: **75**

Все примеры: `categories.meta = Human Interaction`, `difficulty = Hard`, `domain = Общее`. Типы задач: дать рекомендации, дать совет, составить план действий.


### Поля данных

- `instruction` [str] — один из пяти wrapper-промптов из `dataset_meta.json` с плейсхолдером `{question}`
- `inputs.question` [str] — пользовательский запрос
- `outputs` [str] — намеренно пустая строка; не эталон; ответ модели появляется на этапе оценки
- `meta.id` [int]
- `meta.prompt_id` [int] — идентификатор исходного промпта POLLUX
- `meta.source_instruction` [str]
- `meta.categories` — `difficulty`, `domain`, `meta`, `task_type`, `task_subtype`, `task_subsubtype`
- `criteria` [list] — критерии судьи: `criteria_name`, `criteria_description`, `rubrics`, `rubrics_example`
- `reference_answer` [str] — в Human-Centric всегда пусто (оценка без эталона)

### Промпты

Для задачи подготовлено 5 вариантов промптов. Они распределены равномерно по примерам по принципу «один промпт на один пример». Каждый промпт задаёт свободную текстовую генерацию и требует ответ в формате `Ответ: <сгенерированный текст>`. Плейсхолдеры в фигурных скобках (в частности `{question}`) заполняются из полей внутри `inputs` для каждого вопроса. Тексты промптов хранятся в `dataset_meta.json` и продублированы в поле `instruction` каждого примера.

### Создание датасета
Датасет является подвыборкой из закрытой части сета POLLUX, дополняющей публичную версию: [POLLUX](https://arxiv.org/abs/2505.24616). Примеры отобраны по фильтру `Human Interaction` / `Hard` / `Общее`.

### Метрики

- `llm_as_judge`. На каждый элемент `criteria` выполняется отдельный вызов Pollux-4B-Judge через OpenAI-compatible endpoint. Баллы критерия — 0/1/2; итог примера — среднее баллов, делённое на 2.
