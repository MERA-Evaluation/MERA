# T-Math


## Описание задачи

**T-Math** является русскоязычным набором данных с олимпиадными математическими задачами для оценки способностей больших языковых моделей к математическому рассуждению. Задача модели — решить задачу на русском языке и вернуть только итоговый проверяемый ответ.

Датасет содержит 310 задач из [Всероссийской олимпиады школьников](https://vos.olimpiada.ru/) и [Московской олимпиады](https://mos.olimpiada.ru) для школьников за период с 2005 по 2025 год. Условия задач и правильные ответы были извлечены автоматически, а затем проверены асессорами.

Детали представлены в академической статье [T-pro 2.0: An Efficient Russian Hybrid-Reasoning Model and Playground](https://aclanthology.org/2026.eacl-demo.22/)

Тестируемые навыки моделей: Mathematical reasoning, Multi-step problem solving, Russian language understanding

Авторы: T-Pro Team


## Мотивация

Олимпиадные математические задачи являются сложным бенчмарком для языковых моделей, поскольку требуют многошагового рассуждения, внимательной интерпретации условия и умения сформулировать компактный итоговый ответ. T-Math фокусируется на русскоязычных задачах олимпиадного уровня и помогает оценивать reasoning-модели в области, которая хуже представлена в англоцентричных математических бенчмарках.

Датасет спроектирован так, чтобы ответы можно было проверять автоматически: эталонные ответы являются числами или математическими выражениями и могут сравниваться с предсказаниями с помощью инструментов проверки выражений, таких как `math_verify`.


### Для кого результаты

Результаты оценки полезны исследователям и разработчикам языковых моделей, ориентированных на математическое рассуждение на русском языке. Бенчмарк можно использовать для сравнения reasoning-моделей, оценки эффекта instruction tuning или reinforcement learning, а также для отслеживания прогресса в решении олимпиадных задач.


### Ограничения

Датасет не предназначен для оценки общих математических знаний во всех областях математики. В датасете оставлены только задачи с одним проверяемым итоговым ответом, поэтому задачи на доказательство, задачи с несколькими ответами, задачи с нечисловыми ответами и задачи, требующие изображения, исключены. Поскольку датасет содержит олимпиадные задачи, результаты могут существенно зависеть от reasoning budget и параметров декодирования модели.


## Описание датасета

### Поля данных

Каждый вопрос в датасете содержит следующие поля:

- `instruction` [str] — шаблон запроса к языковой модели. Шаблон содержит формулировку задания, плейсхолдер условия задачи и требования к формату ответа.
- `inputs` — вводные данные, формирующие задание для модели:
    - `question` [str] — условие олимпиадной математической задачи.
- `outputs` [str] — строка, содержащая правильный итоговый ответ.
- `meta` — метаданные, относящиеся к тестовому примеру, но не используемые в вопросе (скрытые от тестируемой модели):
    - `id` [int] — номер примера;
    - `grade` [str] — класс, к которому относится задача, или `all`, если класс не указан;
    - `task_complexity` [str] — метка сложности задачи (`EASY`, `MEDIUM` или `HARD`);
    - `olympiad` [str] — олимпиада-источник: `mos` для Московской олимпиады или `vos` для Всероссийской олимпиады школьников;
    - `solutions` [str] — эталонное решение или объяснение;
    - `year` [str] — год или учебный год задачи.


### Пример данных

```json
{
    "instruction": "Привет! Поможешь с задачей?\n\nЗадача:\nНайдите ответ к следующей математической задаче.\n\nУсловие:\n{question}\n\nФормат ответа:\nУкажите только итоговый ответ.",
    "inputs": {
        "question": "Дима спускается на лифте с этажа за 1 минуту, а поднимается пешком после нажатия доступной кнопки. Путь наверх занимает 1 минуту 10 секунд. Лифт и Дима имеют постоянные скорости. На каком этаже живет Дима?"
    },
    "outputs": "7",
    "meta": {
        "id": 329,
        "grade": "all",
        "task_complexity": "MEDIUM",
        "olympiad": "mos",
        "solutions": "Первое решение: Разница между подъемом и спуском составляет 10 секунд. Путь пешком — 1 промежуток между этажами. Второе решение: Решение системы уравнений дает n=7, m=6.",
        "year": "2008"
    }
}
```


### Промпты

Для задачи подготовлено пять вариантов промптов. Каждый промпт просит модель решить математическую задачу и вывести только итоговый ответ. Условие задачи подставляется в плейсхолдер `{question}`.

Варианты промптов, используемые в датасете:

```json
[
    {
        "instruction": "Решите математическую задачу.\n\nУсловие:\n{question}\n\nФормат ответа:\nВыведите только окончательный ответ."
    },
    {
        "instruction": "Привет! Поможешь с задачей?\n\nЗадача:\nНайдите ответ к следующей математической задаче.\n\nУсловие:\n{question}\n\nФормат ответа:\nУкажите только итоговый ответ."
    },
    {
        "instruction": "Помогите мне, пожалуйста.\n\nЗадача:\nРешите математическую задачу и найдите правильный ответ.\n\nУсловие:\n{question}\n\nФормат ответа:\nВ качестве ответа укажите только окончательный ответ."
    },
    {
        "instruction": "Задача:\nВыполните решение математической задачи и определите итоговый результат.\n\nУсловие:\n{question}\n\nФормат ответа:\nВерните только окончательный ответ."
    },
    {
        "instruction": "Задача:\nПо данному условию нужно найти правильный математический ответ.\n\nУсловие:\n{question}\n\nФормат ответа:\nВ ответе укажите только окончательный результат."
    }
]
```


### Создание датасета

Исходные тексты были извлечены из PDF-файлов с помощью [Qwen/Qwen2.5-VL-72B-Instruct](https://huggingface.co/Qwen/Qwen2.5-VL-72B-Instruct). Задачи, правильные ответы и проверяемые числовые ответы были извлечены с помощью LLM-вызовов.

Некорректные вопросы отфильтровывались с помощью LLM по следующим критериям:

- задачи, требующие нескольких ответов;
- задачи без единственного правильного ответа;
- задачи теоремного типа, где основная цель состоит в доказательстве утверждения;
- задачи с нечисловыми ответами;
- задачи, которые невозможно решить без доступа к сопроводительному изображению.

Затем были удалены задачи умеренной сложности, на которых Qwen3-8B достигал 100% pass@16, поскольку такие задачи имели ограниченную ценность для оценки reasoning-моделей. На финальном этапе условия и проверяемые ответы были вручную проверены асессорами на соответствие исходным источникам.


## Оценка


### Метрики

Для агрегированной оценки ответов моделей используются следующие метрики:

- `Exact match`: Метрика Exact match вычисляет среднее по оценкам всех обработанных вопросов, где оценка имеет значение 1, если предсказанная строка точно совпадает с правильным ответом, и 0 в остальных случаях. В этой задаче под точным совпадением подразумевается математическая эквивалентность предсказания и эталонного ответа, которая проверяется с помощью библиотеки `math_verify`.
